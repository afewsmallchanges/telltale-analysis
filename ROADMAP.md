# Development Roadmap
1. Video import
2. Frame-by-frame scrolling / buffer
3. Imported video library
4. Side-by-side video replay with adjustable sync
6. Drawing tools: arrow, circle, pen
7. Timing tools: count down to here, count up from here, count down+up
8. Video framing/crop (persistent zoom on frame)

## Would-be-nice goals
1. Projects - collections of saved clips
2. Audio when playback at realtime
3. Persistent video timestamps; mark points of interest in clip to look at, or skip to.
4. Basic video trim tools (for removing irrelevant chunks of footage - audio can be sacrificed if too complicated)
5. Available as app package
6. Windows / Mac compatability

## Moonshot goals (one day)
1. object / edge detection for point tracking
2. Intelligent object crop - zoom onto target moving in frame, keep target in centre of crop.
3. iOS / Android Support
